\# TROIT



An AI-powered Android voice assistant designed to automate everyday smartphone tasks.



Just say \*\*"Hey Troit"\*\* and interact with your phone using natural voice commands.



\## Features



\- Voice-controlled Android assistant

\- Natural language interaction

\- Tamil and English support (planned)

\- AI-powered responses (planned)

\- Smartphone automation (planned)

\- Hands-free activation (planned)



\## Tech Stack



\- Kotlin

\- Jetpack Compose

\- Android SDK

\- AI integration (planned)
